# Шифр «квадратичная решётка» (решётка Кардано / Флейснера)

GUI-программа на Java + Swing: шифрование и расшифровка текста поворотной решёткой,
редактор ключа мышкой и пошаговая демонстрация работы шифра.

## Запуск

Нужен JDK 8 или новее.

```bash
# вариант 1 — одной командой (Java 11+)
java CardanGrille.java

# вариант 2 — классический
javac -encoding UTF-8 CardanGrille.java
java CardanGrille

# проверка логики шифра без GUI
javac -encoding UTF-8 CardanGrille.java && java CardanGrille --selftest
```

## Что внутри

| Класс | Зачем |
|---|---|
| `Grille` | сама решётка: окошки, повороты, проверка корректности, ключ-строка |
| `GrilleCipher` | шифрование, расшифровка, разбиение на блоки |
| `GrillePanel` | редактор решётки мышкой |
| `DemoPanel` | пошаговая анимация четырёх поворотов |
| `MainWindow` | окно с тремя вкладками |
| `SelfTest` | автопроверка: `--selftest` |

## Формат ключа

`6:012303120` — до двоеточия размер решётки, после двоеточия по одной цифре 0–3
на каждую «четвёрку» клеток (на сколько поворотов сдвинуто её окошко).
Любой ключ такого вида задаёт корректную решётку — испортить её нельзя.

## Как это работает (кратко)

Квадрат N×N, в накладке вырезано N²/4 окошек так, что из каждой «четвёрки»
клеток (клетка + её образы при поворотах на 90°, 180°, 270°) вырезана ровно одна.
Пишем буквы в окошки, поворачиваем решётку на 90° — и так 4 раза; квадрат
заполняется целиком. Шифртекст = квадрат, прочитанный по строкам.
Расшифровка — то же самое в обратную сторону. Подробности — на вкладке
«Справка о шифре» в самой программе.
